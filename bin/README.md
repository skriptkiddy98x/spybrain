# bin/

SpyBrain's phone scan can use [PhoneInfoga](https://github.com/sundowndev/phoneinfoga) (GPL-3.0), a separate program.
It isn't stored in this repository. To use it, or to build the EXE (the build copies it), download the Windows
release **v2.11.0** from https://github.com/sundowndev/phoneinfoga/releases/tag/v2.11.0, rename the program to
`phoneinfoga.exe` and put it in this folder.

Without it everything else works, and the phone scan reports PhoneInfoga as "Not installed".
